iPhone & iPadNo app needed. On your computer tap Show QR (to send to the computer) or Send via QR (to get files), then scan it with the iPhone camera.

First time opening the app

  1. Android: open the downloaded file and allow Install unknown apps when asked.
  2. Windows: if a blue box appears, click More info → Run anyway.
  3. Mac: unzip, drag the app to Applications and open it. If it is blocked, go to System Settings → Privacy & Security → Open Anyway.

All devices must be on the same Wi‑Fi network to share files.
